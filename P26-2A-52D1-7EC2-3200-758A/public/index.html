Catálogo de Filmes e Séries com Avaliações da Turma

Implemente um agregador de críticas audiovisuais voltado para a comunidade de estudantes. Na interface construída com HTML, CSS e JavaScript puro, usuários autenticados pelo Discord podem cadastrar títulos de filmes ou séries (ou selecioná-los de uma lista base), atribuir uma nota de 1 a 5 estrelas e redigir uma resenha curta. As avaliações são armazenadas no Cloudflare D1 com chave composta (user_id + filme_id) para permitir apenas uma nota por pessoa em cada obra, possibilitando edição posterior. As Cloudflare Functions devem agregar a média aritmética de cada título e o total de avaliações para alimentar uma galeria ordenável por nota média, popularidade ou lançamentos recentes.
